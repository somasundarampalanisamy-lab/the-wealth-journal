=== Stages Finance ===
Requires at least: 6.5
Requires PHP: 7.4
License: GPL-2.0-or-later

A fast block theme for a three-stage personal finance blog. Use with the Life Stages plugin.
Edit everything in Appearance → Editor (templates, header, footer, styles, colours).
Stage colours live in Styles → Colours: Starting Out (teal), Growing (blue), Building Wealth (plum).
Fonts: Bricolage Grotesque and IBM Plex Sans, bundled locally (SIL Open Font License).
